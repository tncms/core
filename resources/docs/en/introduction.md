# Introduction

## What is TN CMS?

TN CMS is an open-source Content Management System (CMS) built on Laravel, designed with simplicity, extensibility, and long-term stability in mind.

The project aims to provide a flexible platform for building different types of websites, including:

- Corporate websites
- Personal blogs and content websites
- Online magazines
- Service websites
- E-commerce websites through plugins
- Custom extensions and applications

TN CMS does not aim to replace every other CMS or become the largest project in the ecosystem. Its goal is simply to become a useful, reliable, and maintainable tool for developers and website owners.

---

## Core Foundation

TN CMS is built on modern and widely adopted technologies:

- Laravel as the backend framework
- Filament for the administration panel
- Independent Plugin system
- Theme system separated from the core
- Multi-language support
- Centralized Media Manager
- Built-in SEO essentials
- Demo Importer for quick website setup

The architecture focuses on:

- Minimizing unnecessary dependencies
- Avoiding direct modifications to third-party packages
- Keeping the core stable and maintainable
- Encouraging extensions through Plugins and Themes

---

## Future Goals

TN CMS is developed with a long-term vision.

### Maintain Stable Performance

Many CMS platforms perform well at the beginning but gradually become slower as plugins, themes, and data grow.

TN CMS aims to:

- Keep the core lightweight
- Avoid unnecessary complexity
- Reduce redundant operations
- Maintain consistent performance as websites grow

### Simplify Upgrades

A common problem among CMS platforms is that upgrades may:

- Break existing features
- Cause plugin or theme incompatibilities
- Become difficult when the core has been heavily modified

TN CMS attempts to minimize these issues by:

- Separating Core, Plugins, and Themes
- Avoiding direct modifications to third-party packages
- Providing clear extension points and APIs
- Preserving backward compatibility whenever possible

### Build an Open Ecosystem

The project aims to develop:

- A rich Plugin ecosystem
- Easy-to-build Themes
- Comprehensive documentation
- Developer-friendly tools
- Simple installation and upgrade workflows

---

## Advantages

### Modular Architecture

Core, Plugins, and Themes are designed independently, making development and maintenance easier.

### Easy to Extend

Developers can create new Plugins and Themes without modifying the core system.

### Upgrade Friendly

By avoiding direct changes to framework or vendor packages, upgrades become safer and easier.

### Modern Administration Interface

The admin panel is powered by Filament, providing a modern and user-friendly experience.

### Open Source

Everyone is free to use, study, and contribute to the project.

---

## Limitations

### Still Under Active Development

Some features may change or evolve in future releases.

### Smaller Ecosystem

The number of Plugins, Themes, and community resources is currently smaller compared to long-established CMS platforms.

### Stability Over Feature Quantity

TN CMS does not aim to include every possible feature in the core. Some advanced use cases may require additional Plugins or custom development.

---

## Development Philosophy

TN CMS does not aim to become the biggest or the most feature-rich CMS.

Instead, it aims to provide a platform that is:

- Easy to use
- Easy to extend
- Easy to upgrade
- Stable over the long term
- Genuinely useful for real-world projects

If TN CMS helps people build and manage websites more easily, then the project has achieved its purpose.
